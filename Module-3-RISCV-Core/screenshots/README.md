# Screenshots — RISC-V Core Design

## Overview
This directory stores screenshots captured during the implementation of the RISC-V core design using Xilinx Vivado.

## Purpose
Screenshots provide visual evidence of the design workflow, simulation results, synthesis reports, and implementation results.

## Screenshots to Include

| No. | Screenshot | Description |
|---|---|---|
| 1 | `behavioral_simulation.png` | Simulation waveform showing clock, reset, and output signals. |
| 2 | `rtl_elaboration.png` | Elaborated design and module hierarchy. |
| 3 | `rtl_schematic.png` | Synthesized RTL schematic. |
| 4 | `utilization_report.png` | LUT, flip-flop, and other resource utilization. |
| 5 | `timing_summary.png` | Timing results, including setup and hold slack where available. |
| 6 | `power_report.png` | Estimated power consumption, if generated. |
| 7 | `bitstream_generation.png` | Bitstream generation status, if completed. |

## Guidelines
- Capture screenshots directly from Vivado.
- Use clear filenames that describe the result.
- Include screenshots only after the corresponding step has been performed.
- Do not modify screenshots in a way that misrepresents the results.
- Explain important observations in the main module README.

## Status
Screenshots will be added as the design and simulation workflow progresses.

## Tools Used
- Xilinx Vivado
- Vivado Simulator
