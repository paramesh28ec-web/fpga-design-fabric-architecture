# Module 3 — RISC-V Core Design Using Vivado

## Objective
To understand and implement a RISC-V processor core using RTL design and the Vivado FPGA design flow.

## Tools Used
- Xilinx Vivado
- Verilog HDL
- Git and GitHub

## Reference Repositories
- [FPGA Design Fabric Architecture](https://github.com/ShonTaware/FPGA_Design_Fabric_Architecture)
- [RISC-V Core](https://github.com/shivanishah269/risc-v-core)

## Experiments
1. Source code setup and RTL understanding
2. Behavioral simulation using a testbench
3. RTL elaboration and schematic analysis
4. Logic synthesis and resource utilization
5. Timing analysis and implementation
6. Bitstream generation, if supported by the design setup
