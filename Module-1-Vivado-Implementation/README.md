# Module 1 – Vivado Implementation

## Overview

This module documents the FPGA implementation workflow using AMD/Xilinx Vivado.

## Objectives

- Understand RTL design using Verilog HDL.
- Perform behavioral simulation.
- Run synthesis and implementation.
- Analyze timing and resource utilization.
- Generate an FPGA bitstream.

## Tools Used

- AMD/Xilinx Vivado
- Verilog HDL
- Vivado Simulator
