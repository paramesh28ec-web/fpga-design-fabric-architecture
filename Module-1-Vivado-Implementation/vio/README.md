# VIO – Virtual Input/Output

This folder contains the source files, configuration details, and documentation related to the Virtual Input/Output (VIO) IP used in the Module 1 Vivado implementation.

VIO can be used to monitor internal FPGA signals and drive virtual input signals during live hardware debugging.

## Contents

- VIO IP configuration details
- Generated HDL wrapper or instantiation files, if required
- Related source code and implementation notes

Note: Live VIO debugging requires a compatible physical FPGA board. IP generation alone does not verify hardware operation.
